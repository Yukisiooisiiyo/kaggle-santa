# kaggle-santa

Kaggle「Santa 2026 - The Elf Calculator」用のソルバーです。
各パズルで、初期値から四則演算だけで全ターゲットを作る最短の命令列を探します。

## 現在のスコア

| データ | スコア | 備考 |
|---|---|---|
| practice_puzzles.csv（200問） | 32,888 | `--pick 16 --nodes 100` の1設定。検証スクリプトで valid |

practice 200問は本番1,000問の約1/5の規模です（下界の合計が 5,288 対 26,898）。
公開ノートブック級（本番 138,645）は practice 換算でおよそ 27,300 にあたります。
現状はそれより約2割多く、本番換算でおよそ 167,000 の水準です。

## 使い方

```bash
g++ -O2 -std=c++17 -pthread -o solver src/solver.cpp

# 1設定で解く（200問で約2分）
./solver data/practice_puzzles.csv out/p.csv

# 複数設定で解いて、問題ごとに最短を採用（こちらが本番用）
python3 tools/portfolio.py data/puzzles.csv out/submission.csv

# 検証とスコア計算
python3 src/verify.py data/puzzles.csv out/submission.csv
```

`data/` はコンペのデータ置き場です。再配布できないため git には含めていません。

## 仕組み

レジスタにある値の集合（プール）から、次のターゲットを一番安く作る手順を探して実行する、を繰り返します。

1. **厳密探索**：プールから3命令以内（表を使えば4〜5命令）で作れるかを総当たりで調べます。
2. **共有値の投票**：複数のターゲットから2手以内で届く中間値を先に作ります。
3. **縮約探索**：大きな値 `v` を `v = q*b ± c`、`v = a ± x`、平方根、半分などで小さくし、厳密探索で仕上げます。最良優先探索です。
4. **候補の比較**：残りのターゲットを複数試し、最も安く作れるものから作ります（`--pick`）。
5. **レジスタ管理**：48本を超えたら、最近使っていない大きな値から捨てます。小さな値は残します。
6. **後処理**：どのターゲットにも寄与しない命令を削除します。

## 未確認の前提

Kaggle の Data / Evaluation ページを直接読めていないため、次の点は公開リポジトリの記述からの推定です。
提出前に `sample_submission.csv` と照合してください。

- 提出の `program` 列の書式（現在は `[["+", 0, 1, 4], ...]` の JSON）
- レジスタ番号が0始まりで、初期値が先頭から入ること
- 初期値と同じターゲットは作成済みとして扱われること
- ターゲットを作る順番に制約がないこと

## 主なオプション

| オプション | 既定値 | 意味 |
|---|---|---|
| `--threads` | 2 | 並列数 |
| `--pick` | 1 | 1回に比較するターゲット数 |
| `--nodes` | 200 | 縮約探索の展開数 |
| `--effort` | 1 | 0:深さ3まで / 1:深さ4の表を使う / 2:深さ5も試す |
| `--only ID` | - | 1問だけ解いてターゲットごとの命令数を表示 |
